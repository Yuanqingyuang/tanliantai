# modules/data_review/ — 数据审核、AI 辅助校对与人工确认

> 状态：规划中（首期骨架）

产品第一层与人工把关的交界面：AI 只给候选、依据与置信度，人对每一条映射做出确认或否决。此处是所有"AI 输出进入核算"的唯一闸门。

## 模块职责

| 职责 | 说明 |
| --- | --- |
| AI 候选呈现 | 展示候选列表、依据、置信度与不确定性提示 |
| 人工确认 / 否决 | 记录用户选择，形成 Mapping 确认记录 |
| 异常提示 | 聚合活动数据与因子侧的异常，提示待处理项 |
| 留痕 | 保存模型版本、候选列表、确认记录与时间 |
| 审核状态汇总 | 输出"待确认/已确认/已否决"的进度，供核算前校验 |

## 边界

**做什么**：候选生成与排序（AI 副驾驶）、人工确认交互、确认记录与异常处理留痕。

**不做什么**：
- **不得写入正式核算数值**——AI 只输出候选、依据与置信度，正式数值只能由 `modules/calculation/` 产出。
- 不决定因子取值本身；不改活动数据原值；不执行计算。

## 与 Mapping 实体的对应

| Mapping 字段 | 来源 | 备注 |
| --- | --- | --- |
| 候选 | AI 副驾驶输出 | 含多个候选，附带依据与置信度 |
| 评分 | 候选排序依据 | 排序规则须可解释 |
| 依据 | 检索到的知识/字典/因子条目 | 必须可点开查看 |
| 人工确认 | 用户操作 | 确认或否决；否决需可选填原因 |

Mapping 是"实例"；外部列名到标准字段的映射**规则**归属 `modules/data_dictionary/`。

## 对外接口

| 操作 | 输入 | 输出 | 约束 |
| --- | --- | --- | --- |
| 请求候选 | 物料/工序上下文 | 候选列表 + 依据 + 置信度 | 只读，不落库为正式值 |
| 确认映射 | 候选标识、选择、备注 | Mapping（已确认） | 必须由人操作 |
| 否决映射 | 候选标识、原因 | Mapping（已否决） | 保留全部候选备查 |
| 批量确认 | 候选集合 + 人工复核标记 | 确认记录集合 | 高风险项禁止无复核批量确认 |
| 审核状态查询 | 任务标识 | 待确认/已确认/已否决统计 | 只读 |
| 异常清单 | 任务标识 | 异常记录与处理状态 | 只读 |

## 数据与实体

| 实体 | 关键字段 |
| --- | --- |
| Mapping | 候选、评分、依据、人工确认 |
| 确认记录 | 操作人、时间、选择、备注、模型版本 |
| 异常记录 | 类型、位置、处理说明、状态 |

## 验收要点

| 要点 | 判据 |
| --- | --- |
| AI 边界 | 全流程中 AI 无法写入正式核算数值，也无绕过路径 |
| 三要素同屏 | 候选、依据、置信度必须同时可见 |
| 全程留痕 | 每次确认记录含模型版本、候选集合与操作人 |
| 闸门有效 | 存在未确认 Mapping 时核算被拒绝或显式排除该部分 |
| 实验支撑 | 可支撑实验 A（Top-1 / Top-3 / 人工修正率）与实验 D（字段完整率） |

- 【待确认】批量确认的适用边界与复核要求。
- 【待确认】AI 不可用时的降级流程（纯人工映射）与界面表现。
