# modules/manufacturing/ — PCBA-SMT 工序、设备与生产信息

> 状态：规划中（首期骨架）

承载 PCBA-SMT 工序级建模能力，是"工序活动数据字典"创新的运行侧实现。

## 模块职责

| 职责 | 说明 |
| --- | --- |
| 工序链建模 | 按工序 ID、名称、设备建立工序链与顺序 |
| 设备台账 | 设备标识、类别、关键参数（能耗相关字段按字典注册） |
| 生产批次信息 | 批次、产量、生产期间等用于分摊的基础事实 |
| 工序模板 | 提供 SMT 典型工序骨架供复用 |

## 边界

**做什么**：工序与设备的结构化描述、工序链顺序、与活动数据的挂接点。

**不做什么**：不录入活动量的具体数值（归属 `modules/activity_data/`，其职责是手工录入、模板导入、期间与来源、质量等级判定、缺口识别）；不做分摊计算（归属 `modules/calculation/`）；不解释因子。

## 与知识库的关系

| 对象 | 角色 |
| --- | --- |
| `knowledge/domain/pcba-smt-processes.md` | 工序定义与口径的**依据**（人读规范） |
| 本模块 | 工序与设备的**运行时数据**（可编辑、可版本化） |

两者不一致时以知识库登记的工序口径为准，并登记差异待人工裁决。

## 对外接口

| 操作 | 输入 | 输出 | 约束 |
| --- | --- | --- | --- |
| 列取工序模板 | 无 | 工序模板列表 | 只读 |
| 创建工序 | 工序 ID、名称、设备、上游工序 | Process | 工序 ID 唯一；须属于已声明边界 |
| 建链 | 工序 ID 列表/顺序 | 工序链 | 不允许成环 |
| 登记设备 | 设备标识、类别、参数 | 设备记录 | 参与核算的设备变更需留痕 |
| 查询工序链 | 任务标识 | Process 列表（含顺序） | 只读 |

## 依赖

| 方向 | 对象 | 说明 |
| --- | --- | --- |
| 上游 | `knowledge/domain/pcba-smt-processes.md` | 工序定义与口径 |
| 上游 | `modules/project/` | 核算边界与任务上下文 |
| 上游 | `modules/data_dictionary/` | 字段与单位注册 |
| 下游 | `modules/activity_data/` | 按工序挂接活动量 |
| 下游 | `modules/calculation/` | 消费工序链用于分摊与汇总 |

## 数据与实体

| 实体 | 关键字段 | 备注 |
| --- | --- | --- |
| Process | 工序 ID、名称、设备 | 契约见 `contracts/README.md` |
| 设备记录 | 设备标识、类别、参数 | 参数口径由字典定义 |
| 工序链 | 有序工序引用、顺序号 | 与任务绑定 |

## 验收要点

| 要点 | 判据 |
| --- | --- |
| 字典一致 | 全部工序 ID 与名称可在知识库/字典中检索到 |
| 链路完整 | 工序链无环、无孤立工序被引用 |
| 可追溯 | 工序或设备变更留下记录并可在数据包中呈现 |
| 模板可用 | 新建任务可基于模板一键生成 SMT 典型工序链 |

## 待确认项

- 【待确认】SMT 典型工序集合的最终清单（印刷、贴片、回流焊、AOI、分板等以知识库登记为准）。
- 【待确认】设备能耗参数是否需要采集实时/计量数据。
- 【待确认】是否支持子工序与嵌套工序链。
- 【待确认】生产批次与活动数据期间的对应粒度（批次 / 日 / 月）。
- 【待确认】多产线、多工厂维度是否纳入本模块。
