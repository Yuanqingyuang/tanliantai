# modules/data_dictionary/ — 碳数据字典与字段定义

> 状态：规划中（首期骨架）

把"工序级碳数据字典"落成可注册、可比对、可版本化的字段定义，是产品第一项创新的运行侧载体。

## 模块职责

| 职责 | 说明 |
| --- | --- |
| 字段注册 | 注册字段名、类型、是否必填、所属实体 |
| 单位与口径 | 每个字段绑定单位与口径说明，禁止游离单位 |
| 映射规则 | 定义外部表格列名到标准字段的映射规则（供导入与数据包字段映射复用） |
| 字典版本 | 维护字典版本（V0.1 / V1.0）与版本间差异 |
| 覆盖率评审 | 输出字段覆盖率报告，支撑评审结论 |

## 边界

**做什么**：字段与单位的**定义**、映射规则、字典版本管理、覆盖率统计。

**不做什么**：不存储业务数据值；不执行核算；不决定因子取值；不替代 `contracts/` 的接口定义。

## 与 contracts/ 的关系

| 对象 | 角色 |
| --- | --- |
| `contracts/README.md` | 定义模块间**接口与数据结构**（跨模块稳定性承诺） |
| 本模块 | 定义**字段语义、单位与口径**（数据含义的单一事实来源） |

字段含义变更先改本模块并升版本，再评估是否构成契约破坏性变更（需 ADR）。

## 对外接口

| 操作 | 输入 | 输出 | 约束 |
| --- | --- | --- | --- |
| 查询字段定义 | 实体名、字典版本 | 字段定义列表（名/类型/单位/必填） | 只读，按版本返回 |
| 校验字段值 | 实体名、字段名、值 | 校验结论 + 违规原因 | 不写入数据 |
| 注册字段 | 字段定义、变更依据 | 新字典版本 | 需依据；破坏性改写需 ADR |
| 生成映射建议 | 外部列名集合 | 候选映射 + 置信度 | 仅候选，需人工确认 |
| 覆盖率报告 | 字典版本、目标实体集合 | 覆盖率与缺口清单 | 只读 |

## 数据与实体

| 实体 | 关键字段 | 备注 |
| --- | --- | --- |
| 字段定义 | 实体名、字段名、类型、单位、必填、口径说明 | 按字典版本组织 |
| 字典版本 | 版本号、生效说明、差异清单 | V0.1 为首个规划版本 |
| 映射规则 | 外部列名、标准字段、转换说明 | 与 Mapping 实体区分：此处是规则，那里是实例 |

## 验收要点

| 要点 | 判据 |
| --- | --- |
| 覆盖率 | V0.1 覆盖产品三层与八个核心实体所需字段，缺口显式列出 |
| 无游离单位 | 所有数值字段均绑定单位 |
| 版本可比 | 任意两版本可输出字段级差异 |
| 映射可复核 | 映射建议给出的依据可被人读懂并裁决 |
