# modules/calculation/ — 确定性碳核算引擎

> 状态：规划中（首期骨架）

产品第二层：规则约束 → 人工确认 → 确定性计算 → 版本与结果指纹。本模块是唯一被允许产出正式核算数值的地方。同一输入必须得到同一结果。

## 模块职责

| 职责 | 说明 |
| --- | --- |
| 规则约束 | 按已登记的边界、单位、口径、因子适用性做前置约束检查 |
| 确定性计算 | 依据公式登记表执行计算，不使用随机或不可复现步骤 |
| 分摊方法切换 | 支持产量 / 设备时间 / 贴片点数 / 多因素分摊，并记录所用方法 |
| 输入快照 | 冻结本次计算所用的全部输入（活动数据、因子、字典与规则版本） |
| 结果指纹 | 为每次计算生成指纹，供引用、复算与审计 |
| 可回放 | 支持按快照与版本重放一次核算并比对结果 |

## 边界

**做什么**：约束检查、计算执行、分摊、快照与指纹、结果落库与版本记录。

**不做什么**：不产生 AI 候选；不替代人工确认；不定因子；不改字典；不生成数据包文档结构。

## 输入输出

| 方向 | 内容 | 说明 |
| --- | --- | --- |
| 输入 | 已确认的 Mapping、ActivityData、因子快照、边界与功能单位、规则版本、分摊方法 | 任一缺失即拒绝运行 |
| 输入 | 字典版本 | 决定单位与口径解释 |
| 输出 | CalculationRun：输入快照、规则版本、结果、指纹 | 唯一正式数值出口 |
| 输出 | 分摊明细、贡献分解 | 供 `modules/analysis/` 消费 |

## 必须满足的性质

| 性质 | 判据 |
| --- | --- |
| 确定性 | 同一输入快照 + 同一规则版本 → 逐位一致的结果与指纹 |
| 可复算 | 任一历史运行可用其快照重放并获得一致结果 |
| 可解释 | 每个结果值可下钻到公式、输入、因子来源 |
| 无隐式默认 | 缺失输入必须报错，禁止静默采用默认值 |
| 留痕 | 运行发起人、时间、所用版本、确认记录一并保存 |

## 与 knowledge/formulas 的对应

- 计算所用的每条公式必须在 `knowledge/formulas/formula-register.md` 登记，引擎只实现已登记公式。
- 公式变更须有依据，并同步更新登记表与变更记录（R3：无依据不改核算）。
- 引擎中的公式实现与登记表条目需一一对应，便于评审逐条核对。

## 对外接口

| 操作 | 输入 | 输出 | 约束 |
| --- | --- | --- | --- |
| 前置校验 | 任务标识 | 约束检查报告 | 不通过则不可运行 |
| 发起核算 | 任务、确认记录、分摊方法 | CalculationRun（结果 + 指纹） | 需人工确认齐备 |
| 指定分摊方法 | 核算运行、方法、参数 | 分摊明细 | 方法须在登记范围内 |
| 复算 | 历史运行标识 | 新运行 + 与历史的一致性结论 | 只读引用历史快照 |
| 查询指纹 | 运行标识 | 指纹与版本信息 | 只读 |

## 验收要点

| 要点 | 判据 |
| --- | --- |
| 确定性回归 | 固定输入集重复运行 N 次，结果与指纹完全一致 |
| 四组实验支撑 | 可支撑实验 B（资源分摊差异与敏感性）与 D（复算一致率） |
| 拦截能力 | 未确认 Mapping、缺因子、缺单位均被拒绝并给出原因 |
| 数值可下钻 | 任一分项可展开到公式与输入行 |
| 测试资产 | 测试输入集中于 `tests/fixtures/README.md` 约定的位置 |

## 回归测试要求

- 每次公式、因子、分摊方法或单位口径变更后，必须重跑全量回归。
- 回归集至少覆盖：正常路径、边界值、缺输入、单位不一致、分摊方法切换。
- 回归结果需记录指纹基线；指纹变化即视为行为变更，必须说明原因。

## 待确认项

- 【待确认】实现语言与数值精度/舍入规则。
- 【待确认】分摊方法的完整清单与优先级（产量 / 设备时间 / 贴片点数 / 多因素）。
- 【待确认】多因素分摊的权重确定方式。
- 【待确认】指纹算法与其稳定性承诺。
- 【待确认】核算运行是否支持增量重算（部分输入变更时）。
