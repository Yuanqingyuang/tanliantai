# modules/data_package/ — 核算数据包生成与解析

> 状态：规划中（首期骨架）

产品第三层交付物：把结果、证据、缺口、字段映射与修改记录打包成可交付、可复核的文件。

## 模块职责

| 职责 | 说明 |
| --- | --- |
| 打包 | 按固定清单组装核算结果、活动数据、因子来源与版本、缺口与质量等级、修改记录、字段映射、计算指纹 |
| 解析 | 读入既有数据包并校验结构与完整性 |
| 版本兼容 | 声明数据包版本并提供兼容性判定 |
| 完整性校验 | 输出字段完整率与可复算性检查结论 |
| 复算入口 | 支持以数据包为输入触发复算（经 `modules/calculation/`） |

## 边界

**做什么**：数据包的结构定义实现、生成、解析、校验、兼容性提示。

**不做什么**：不定义核算逻辑；不修改结果；不做字段语义定义（归属 `modules/data_dictionary/`）；不替用户决定是否披露敏感字段。

## 打包内容清单

| 章节 | 内容 | 来源 |
| --- | --- | --- |
| 结果 | 总量与分项、分摊明细 | `modules/calculation/` |
| 活动数据 | 输入的活动量与来源 | `modules/activity_data/` |
| 因子与版本 | 因子值、来源、单位、区域、版本 | `modules/emission_factors/` 快照 |
| 缺口与质量 | 缺口清单、质量等级 | `modules/activity_data/` |
| 字段映射 | 外部列名到标准字段的对应 | `modules/data_dictionary/` 规则 + Mapping 实例 |
| 修改记录 | 关键变更的人、时间、内容 | 各模块留痕汇总 |
| 计算指纹 | 运行指纹与所用规则/字典版本 | `modules/calculation/` |

## 与 DataPackage 实体的对应

| DataPackage 字段 | 说明 |
| --- | --- |
| 结果 | 正式核算输出，不得改写 |
| 证据 | 输入、依据、确认记录的可复核集合 |
| 缺口 | 缺失项与影响说明 |
| 字段映射 | 便于第三方工具理解字段含义 |

## 对外接口

| 操作 | 输入 | 输出 | 约束 |
| --- | --- | --- | --- |
| 生成数据包 | 运行标识、选项（是否含敏感字段） | 数据包文件 + 生成报告 | 结果只读引用 |
| 校验数据包 | 数据包文件 | 完整率、可复算性结论 | 只读，不修改原文件 |
| 解析数据包 | 数据包文件 | 结构化内容 | 结构不符须逐项报错 |
| 兼容性判定 | 数据包版本、当前版本 | 可读/需迁移/不支持 | 需说明原因 |
| 触发复算 | 数据包文件 | 复算运行标识 | 经核算引擎执行 |

## 验收要点

| 要点 | 判据 |
| --- | --- |
| 字段完整率 | 数据包必填章节与字段全部齐备；缺失项显式列出 |
| 可复算率 | 由数据包复算的结果与原始结果一致（目标以待确认口径统计） |
| 不可篡改 | 数据包含指纹；被修改后校验可发现 |
| 脱敏可控 | 敏感字段默认不写入或遮蔽，选择留痕 |
| 实验支撑 | 可支撑实验 D（复算一致率、字段完整率） |
