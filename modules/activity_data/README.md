# modules/activity_data/ — 活动数据录入、管理与导入

> 状态：规划中（首期骨架）

活动数据是核算的输入事实。本模块把工厂侧的现实（活动量、单位、期间、来源）变成可校验、可分级的结构化记录。

## 模块职责

| 职责 | 说明 |
| --- | --- |
| 手工录入 | 按工序/设备录入活动量、单位、期间与来源 |
| 模板导入 | 按模板批量导入，逐行给出成功/失败/警告 |
| 期间与来源 | 绑定数据期间与来源（计量、台账、估算等） |
| 质量等级判定 | 按来源与完整性判定质量等级（等级定义见字典） |
| 缺口识别 | 标出缺失期间、缺失单位、缺失来源的记录 |

## 边界

**做什么**：活动数据的采集、校验、分级、缺口标注与版本留痕。

**不做什么**：不做因子匹配；不做分摊与计算；不定义工序（归属 `modules/manufacturing/`）；不定义字段（归属 `modules/data_dictionary/`）。

## 数据校验规则

| 规则类型 | 示例判据 | 处理 |
| --- | --- | --- |
| 必填 | 活动量、单位、期间、来源齐全 | 缺项只能存草稿 |
| 单位口径 | 单位须在字典注册且与工序匹配 | 拒绝并提示可选项 |
| 范围 | 活动量落在该工序合理区间内 | 超范围标记异常待说明 |
| 统计异常 | 与同工序历史分布显著偏离 | 提示异常并留处理说明 |
| 一致性 | 期间不重叠、不越界 | 冲突需人工裁决 |

## 导入模板

- 模板为列名与字段的显式映射，列名到标准字段的对应以 `modules/data_dictionary/` 的映射规则为准。
- 导入结果必须包含：总行数、成功行数、失败行数与逐行原因。
- 导入是"追加 + 可回滚"的操作：一次导入可整体撤销，撤销留痕。
- 模板与示例数据位置见 `data/templates/README.md`、`data/examples/README.md`（示例必须脱敏）。

## 对外接口

| 操作 | 输入 | 输出 | 约束 |
| --- | --- | --- | --- |
| 新增活动数据 | 工序/设备、活动量、单位、期间、来源 | ActivityData | 校验通过才可置为有效 |
| 批量导入 | 文件/表格 + 映射 | 导入报告 | 逐行结果；失败不静默丢弃 |
| 查询活动数据 | 任务、工序、期间 | ActivityData 列表 | 只读 |
| 标注异常处理 | 记录标识、说明 | 处理留痕 | 说明必填 |
| 缺口清单 | 任务标识 | 缺口字段与期间列表 | 只读，供数据包引用 |

## 依赖

| 方向 | 对象 | 说明 |
| --- | --- | --- |
| 上游 | `modules/data_dictionary/` | 字段、单位、质量等级定义 |
| 上游 | `modules/manufacturing/` | 工序与设备 |
| 下游 | `modules/calculation/` | 作为输入快照的组成部分 |
| 下游 | `modules/data_package/` | 缺口与质量等级进入数据包 |

## 数据与实体

| 实体 | 关键字段 |
| --- | --- |
| ActivityData | 活动量、单位、期间、来源、质量等级 |
| 导入批次 | 批次标识、映射、结果统计、可回滚标记 |
| 异常记录 | 记录标识、异常类型、处理说明 |

## 验收要点

| 要点 | 判据 |
| --- | --- |
| 无脏数据入库 | 校验失败记录不进入有效数据集 |
| 导入可解释 | 任一失败行可定位到具体单元格与规则 |
| 缺口可见 | 缺口清单可导出并进入数据包章节 |
| 分级有据 | 质量等级判定依据对用户可见 |
