# modules/analysis/ — 核算结果、构成与对比分析

> 状态：规划中（首期骨架）

把 CalculationRun 的结果展开成可读懂、可讨论、可支撑决策的视图。分析层只做呈现与派生统计，不产出新的正式核算数值。

## 模块职责

| 职责 | 说明 |
| --- | --- |
| 总量与分项构成 | 按工序、物料、能源等维度分解总量 |
| 贡献排序 | 工序/物料贡献排序（帕累托视角） |
| 方案对比 | 多方案（不同分摊方法/边界/因子版本）横向对比 |
| 敏感性分析 | 关键输入变动对结果的影响方向与幅度 |
| 口径区分 | 与管理口径结果分区显示，避免混淆 |
| 导出 | 生成可引用的分析输出（图表数据、摘要） |

## 边界

**做什么**：读取核算结果做聚合、排序、对比与敏感性呈现。

**不做什么**：不重新计算正式数值（派生统计除外，且必须标注为派生）；不修改核算结果；不生成数据包文件结构。

## 分析口径与派生值

| 类型 | 定义 | 呈现要求 |
| --- | --- | --- |
| 核算值 | CalculationRun 的正式输出 | 必须附指纹与版本 |
| 派生值 | 基于核算值的比率、占比、排序 | 标注"派生"，给出计算口径 |
| 管理口径 | 用户自定义的分摊或归类视角 | 显式分区，禁止与核算值混排 |

## 输出可视化要求

| 图表 | 用途 | 要求 |
| --- | --- | --- |
| 分项构成（占比） | 一眼看清主要贡献 | 支持下钻到工序/物料条目 |
| 贡献排序（条形 + 累计） | 定位关键少数 | 标注累计占比与阈值线 |
| 方案对比（并列） | 分摊方法/边界差异 | 同时显示差异绝对值与相对差异 |
| 敏感性（龙卷风/区间） | 识别高影响输入 | 必须说明扰动范围与依据 |
| 缺口与质量叠加 | 结论可信度提示 | 缺口与低质量等级数据须显式标注 |

所有图表都可导出图表数据；配色不作为唯一信息通道。

## 对外接口

| 操作 | 输入 | 输出 | 约束 |
| --- | --- | --- | --- |
| 查询构成 | 运行标识、维度 | 分项构成数据 | 只读，含指纹 |
| 贡献排序 | 运行标识、维度、排序键 | 排序列表 | 只读 |
| 方案对比 | 运行标识集合 | 差异表 | 需说明可比性前提 |
| 敏感性分析 | 运行标识、扰动输入集合 | 影响区间 | 不得产出新的正式核算值 |
| 导出分析 | 视图标识、格式 | 图表数据/摘要 | 【待确认】格式 |

## 验收要点

| 要点 | 判据 |
| --- | --- |
| 可追溯 | 每个图表点位可回溯到具体输入行与公式 |
| 口径不混 | 管理口径数据绝不与核算值同图同表 |
| 缺口可视 | 存在数据缺口时结论旁必须有显式提示 |
| 敏感性可复核 | 扰动范围、方法、依据全部写明 |
| 实验支撑 | 可支撑实验 B（资源分摊差异与敏感性）与实验 C（流程效率）的产出一致性 |
