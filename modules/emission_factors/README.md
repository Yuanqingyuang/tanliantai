# modules/emission_factors/ — 排放因子管理（软件侧）

> 状态：规划中（首期骨架）

管理软件运行时使用的排放因子：入库、四重校验、快照与版本。因子是核算数值的直接来源，因此本模块的一切改动都必须留痕。

## 模块职责

| 职责 | 说明 |
| --- | --- |
| 因子入库 | 登记因子值、单位、区域、来源、版本 |
| 四重校验 | 来源 / 单位 / 区域 / 版本四项缺一不可，任一缺失即不可用于核算 |
| 因子快照 | 核算运行时冻结所用因子集合，供复算与审计 |
| 版本管理 | 因子集合的版本标识与差异说明 |
| 适用性提示 | 向用户提示区域/年份不匹配等风险 |

## 边界

**做什么**：因子的运行时可查询、可校验、可快照、可版本化。

**不做什么**：不生产因子数值、不解释标准条款；不做因子与物料的匹配决策（归属 `modules/data_review/`）；不执行计算。

## 与知识库的关系

| 对象 | 角色 |
| --- | --- |
| `knowledge/emission-factors/factor-register.md` | 因子的**依据**与登记来源（人读、需引用出处） |
| 本模块 | 因子的**运行时数据**（供核算调用、可快照） |

新增或修改因子前必须先更新因子登记表；两者不一致时以登记表为准并暂停该因子的可用性。

## 对外接口

| 操作 | 输入 | 输出 | 约束 |
| --- | --- | --- | --- |
| 查询因子 | 物料/能源类别、区域、版本 | EmissionFactor 候选 | 只读 |
| 校验因子完整性 | 因子标识 | 四重校验结论 + 缺失项 | 缺失项须逐项列出 |
| 创建因子快照 | 因子标识集合、用途 | 快照标识 | 快照一经核算引用即不可变 |
| 登记/更新因子 | 因子值、单位、区域、来源、版本 | 新因子版本 | 需依据；更新需留痕 |
| 差异对比 | 两个版本 | 因子级差异清单 | 只读 |

## 依赖

| 方向 | 对象 | 说明 |
| --- | --- | --- |
| 上游 | `knowledge/emission-factors/factor-register.md` | 因子依据与出处 |
| 上游 | `modules/data_dictionary/` | 单位与类别字段定义 |
| 下游 | `modules/data_review/` | 提供候选因子供 AI 排序与人工确认 |
| 下游 | `modules/calculation/` | 消费快照作为计算输入 |

## 数据与实体

| 实体 | 关键字段 |
| --- | --- |
| EmissionFactor | 因子值、单位、区域、来源、版本 |
| 因子快照 | 快照标识、因子集合、创建时的版本、用途 |
| 更新记录 | 因子标识、旧值/新值、依据、责任人 |

## 验收要点

| 要点 | 判据 |
| --- | --- |
| 四重校验 | 任一要素缺失的因子无法进入核算 |
| 快照不可变 | 已被 CalculationRun 引用的快照不可被改写 |
| 可追溯 | 每个因子值可回溯到 `knowledge/emission-factors/factor-register.md` 的条目 |
| 复算一致 | 相同快照版本复算得到相同结果 |

## 待确认项

- 【待确认】因子库的组织粒度（按能源/物料/工序）与检索键。
- 【待确认】区域维度的取值集合（国家/电网区域/省）。
- 【待确认】因子版本与核算规则版本是否需要联动升级。
- 【待确认】因子值本身是否允许用户自定义录入，以及自定义因子的审计要求。
- 【待确认】是否需要因子变更的影响面分析（哪些历史核算受影响）。
