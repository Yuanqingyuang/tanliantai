# modules/project/ — 项目、产品与核算任务

> 状态：规划中（首期骨架）

管理核算的顶层对象：为哪个产品、在什么边界与功能单位下、开展哪一次核算任务。

## 模块职责

| 职责 | 说明 |
| --- | --- |
| 产品台账 | 维护 Product：产品编码、规格、核算边界与单位 |
| 核算任务 | 创建/归档核算任务，绑定产品与目标数据包 |
| 边界与功能单位 | 记录边界声明与功能单位，作为所有数值的口径前提 |
| 任务上下文 | 向其他模块提供当前产品与任务的标识与版本 |

## 边界

**做什么**：产品与任务的生命周期、边界与功能单位的声明与变更留痕。

**不做什么**：不解析 BOM；不录入活动数据；不做因子匹配；不执行计算；不生成数据包内容。

## 核心对象

| 对象 | 关键字段 | 单位/口径 |
| --- | --- | --- |
| Product | 产品编码、规格、核算边界、功能单位 | 口径以声明为准，必须显式 |
| 核算任务 | 任务标识、关联产品、状态、负责人 | 状态流转需留痕 |
| 边界声明 | 边界类型、覆盖工序范围、排除项 | 与 `modules/calculation/README.md` 一致 |

## 对外接口

| 操作 | 输入 | 输出 | 约束 |
| --- | --- | --- | --- |
| 创建产品 | 产品编码、规格 | Product | 编码唯一 |
| 更新产品 | Product 标识、变更字段 | 变更记录 | 已参与核算的边界变更需新建版本 |
| 创建核算任务 | 产品标识、核算目的 | 任务标识 | 必须绑定已声明的边界与功能单位 |
| 查询任务上下文 | 任务标识 | 产品 + 边界 + 功能单位 | 只读 |
| 归档任务 | 任务标识、原因 | 归档状态 | 归档后只读 |

## 依赖

| 方向 | 对象 | 说明 |
| --- | --- | --- |

| 上游 | `app/startup/` | 存储与配置就绪 |
| 下游 | `modules/calculation/` | 消费边界与功能单位 |
| 下游 | `modules/data_package/` | 消费任务标识用于打包 |

## 数据与实体

- 实体：Product、核算任务、边界声明；字段定义以 `modules/data_dictionary/README.md` 注册为准。
- 变更必须留痕（谁、何时、改了什么），供数据包"修改记录"章节引用。
- 【待确认】产品编码规则与外部系统编码的对齐方式。

## 验收要点

| 要点 | 判据 |
| --- | --- |
| 口径完整性 | 未声明边界或功能单位的产品无法创建核算任务 |
| 变更可追溯 | 任一字段历史值可查询 |
| 多产品隔离 | 不同产品的 BOM、活动数据、结果不串扰 |
| 归档只读 | 归档任务不可被修改或重新计算 |

## 待确认项

- 【待确认】项目/产品的层级是否需要"项目 → 产品 → 任务"三级。
- 【待确认】一个产品是否允许存在多个并行的核算任务。
- 【待确认】产品编码的唯一性范围（全局 / 项目内）。
- 【待确认】是否需要与外部 PDM/ERP 编码映射；若需要，映射归属本模块还是 `modules/data_dictionary/`。
- 【待确认】任务状态机的具体状态集合。
