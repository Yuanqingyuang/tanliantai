## 2. 实验卡（每实验一张）

### 实验 A：AI 匹配

| 项目 | 内容 |
|---|---|
| **输入数据** | `tests/fixtures/A_mapping/` 下的 BOM 行、工序字典、已确认映射基准 |
| **步骤** | 1. 加载基准映射集<br>2. 对每行 BOM 调用 AI 副驾驶获取 Top-3 候选<br>3. 与基准逐行比对，记录 Top-1/Top-3 命中、人工修正<br>4. 计算三指标及 95% CI |
| **预期产出** | `tests/acceptance/reports/A_matching_report.md`：含指标表、CI、逐行明细、失败样例列表 |
| **失败判定** | 任一指标未达阈值、或样本量 < 100、或 CI 下界 < 阈值 |
| **数据版本** | `fixtures/A_mapping/v<日期>.csv` + 代码 commit hash |

### 实验 B：资源分摊

| 项目 | 内容 |
|---|---|
| **输入数据** | `tests/fixtures/B_allocation/` 共因资源池、产品产量/工时/点数、多因素权重 |
| **步骤** | 1. 加载 4 种分摊方法参数<br>2. 执行分摊，验证守恒（B-01）<br>3. 对关键参数 ±10% 扰动，计算敏感性（B-02）<br>4. 方法间两两比较（B-03） |
| **预期产出** | `tests/acceptance/reports/B_allocation_report.md`：守恒差异表、敏感性龙卷风图、方法间差异矩阵 |
| **失败判定** | 守恒差异 > 0.1%、或敏感性 > 5%、或方法间差异超【待确认阈值】 |
| **数据版本** | `fixtures/B_allocation/v<日期>.json` + 代码 commit hash |

### 实验 C：流程效率

| 项目 | 内容 |
|---|---|
| **输入数据** | `tests/fixtures/C_efficiency/` 20 个脱敏完整 BOM 样例包 |
| **步骤** | 1. 同一人/同机器先用 Excel 手工完成全流程，计时（C-01）<br>2. 再用工具端到端完成，计时（C-02）<br>3. 双方结果与基准比对，统计错误率（C-03）<br>4. 记录机器配置、人员背景、日期 |
| **预期产出** | `tests/acceptance/reports/C_efficiency_report.md`：耗时箱线图、加速比、错误率、原始记录表 |
| **失败判定** | 加速比 < 3.3×、或错误率 > 2%、或样本量 < 20 |
| **数据版本** | `fixtures/C_efficiency/v<日期>.xlsx` + 记录表 commit hash |

### 实验 D：可审计性

| 项目 | 内容 |
|---|---|
| **输入数据** | `tests/fixtures/D_audit/` 10 个已生成的 DataPackage |
| **步骤** | 1. 对每个包运行复算脚本，比对结果指纹（D-01）<br>2. 解析包结构，统计必填字段完整率（D-02）<br>3. 抽查审计链字段（人/时间/规则/因子版本）完整性（D-03） |
| **预期产出** | `tests/acceptance/reports/D_audit_report.md`：复算一致表、字段完整表、审计链抽查明细 |
| **失败判定** | 任一指标 < 100%、或样本量 < 10 |
| **数据版本** | `fixtures/D_audit/v<日期>/` + 复算脚本 commit hash |
