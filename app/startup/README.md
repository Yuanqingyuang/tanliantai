# app/startup/ — 启动与初始化

> 状态：规划中（首期骨架）

负责在用户可见界面出现之前，把运行所需的一切准备到"可用且可解释"的状态。启动路径必须幂等、可重试、失败可定位。

## 模块职责

| 职责 | 说明 |
| --- | --- |
| 配置加载 | 读取配置、校验必填项、给出默认值来源 |
| 日志 | 建立日志与操作日志通道，确定级别与落盘位置 |
| 存储连接 | 连接数据存储、校验 schema 版本、准备数据目录 |
| 知识库加载 | 加载并校验因子库与领域知识（版本、单位、来源完整性） |
| 模块注册 | 按契约装配模块，校验依赖与版本兼容性 |
| 界面呈现 | 完成自检后交出控制权给 `app/shell/` |

## 边界

**做什么**：启动序列编排、失败降级、自检、配置项暴露。

**不做什么**：不实现业务规则；不在启动期执行核算；不修改因子或字典内容（只读取与校验）。

## 启动序列

| 序 | 阶段 | 输入 | 输出 | 失败处理 |
| --- | --- | --- | --- | --- |
| 1 | 配置加载 | 配置文件 / 环境变量 | 已校验的配置快照 | 致命：可读错误页并给出缺失项 |
| 2 | 日志初始化 | 日志级别、落盘路径 | 日志与操作日志通道 | 致命：降级为仅内存日志并提示 |
| 3 | 数据存储连接 | 存储配置 | 连接与 schema 版本 | 致命：进入只读或不可用页 |
| 4 | 知识库 / 因子库加载校验 | 本地知识库路径 | 版本号、校验结果 | 警告：允许进入但禁用核算 |
| 5 | 模块注册 | 注册表 + 契约版本 | 就绪模块清单 | 降级：缺失模块在工作台标灰 |
| 6 | 界面呈现 | 已就绪运行时 | 主窗口 / 工作台 | — |

## 失败与降级策略

| 级别 | 触发条件 | 行为 |
| --- | --- | --- |
| 致命 | 配置不可读、存储不可用、契约主版本不兼容 | 阻断进入工作台，展示原因与修复建议 |
| 警告 | 因子库版本旧、字典版本缺失、可选模块缺失 | 允许进入，相关功能标灰并说明 |
| 信息 | 数据目录首次创建、缓存未命中 | 静默处理并记录日志 |

启动失败必须可重试且不产生半初始化状态；重试不得覆盖既有用户数据。

## 本地部署与离线要求

- 全流程须在无外网环境下可用；AI 能力不可用时工作流仍可人工完成。
- 启动过程中不得强制联网校验；仅允许读取本地路径或已显式配置的服务。
- 敏感数据不出本机（BOM 敏感，见合规内建：最小权限、脱敏、访问与操作日志）。

## 配置项清单

| 配置项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `data_dir` | 路径 | 【待确认】 | 活动数据与核算结果存储根目录 |
| `knowledge_dir` | 路径 | 【待确认】 | `knowledge/` 知识库根目录 |
| `factor_register_version` | 字符串 | 【待确认】 | 期望加载的因子登记版本 |
| `log_level` | 枚举 | 【待确认】 | 日志级别 |
| `log_dir` | 路径 | 【待确认】 | 日志落盘路径 |
| `offline_mode` | 布尔 | 【待确认】 | 是否强制离线 |
| `deployment_mode` | 枚举 | 【待确认】 | 本地 / 内网服务；与 `app/` 形态 ADR 联动 |
| `enable_ai_assist` | 布尔 | 【待确认】 | AI 副驾驶开关；关闭后仅人工流程 |
| `legacy_lock_mode` | 枚举 | 【待确认】 | 【待确认】锁定已发布核算结果的方式 |

## 健康自检

启动结束时输出自检报告（供 `shell/` 呈现与排障），至少包含：

| 检查项 | 通过条件 |
| --- | --- |
| 配置完整性 | 必填项齐全且路径可读写 |
| 存储连通与版本 | schema 版本与外壳期望一致 |
| 因子库完整性 | 每条因子具备来源、单位、区域、版本四要素 |
| 字典版本 | 存在可用字段定义版本（V0.1 / V1.0） |
| 模块就绪 | 必需模块已注册且契约版本兼容 |

## 验收要点

- [ ] 全新环境首次启动可在无人工干预下完成目录初始化并通过自检。
- [ ] 断开网络后启动不报致命错误。
- [ ] 因子库缺失时给出警告并阻断核算入口，而非静默产出数值。
- [ ] 自检报告可导出，用于问题复现。

## 待确认项

- 【待确认】存储形态（嵌入式 / 关系型 / 文件）与 schema 迁移策略。
- 【待确认】知识库与因子库的加载格式与校验方式。
- 【待确认】`legacy_lock_mode` 的含义与取值，见 `docs/decisions/README.md`。
- 【待确认】升级路径：是否支持原地升级与数据迁移，迁移失败如何回滚。
- 【待确认】多用户模式下启动时的会话与权限上下文来源。
