# app/shell/ — 主窗口与工作台

> 状态：规划中（首期骨架）

主窗口、导航与工作台视图层。导航以核算工作流为主线，把模块能力串成一条可复核的路径。

## 模块职责

| 职责 | 说明 |
| --- | --- |
| 导航结构 | 工作流步骤的入口、进度与回退 |
| 工作台承载 | 为各模块视图提供宿主、上下文与统一交互 |
| 状态与错误呈现 | 加载、空态、部分失败、错误、冲突提示 |
| 权限与脱敏提示 | 按角色隐藏/遮蔽字段并显式说明原因 |
| 中文本地化与可访问性 | 全中文界面、键盘可达、术语一致 |

## 边界

**做什么**：视图编排、用户输入采集、结果显示、确认交互、状态提示。

**不做什么**：不做数值计算与规则判定；不直接读写存储；不定义数据包格式；不替用户做确认决策。

## 导航结构（建议工作流）

| 步骤 | 视图 | 主要输入 | 主要输出 |
| --- | --- | --- | --- |
| 1 | 项目 / 产品 | 产品编码、规格、核算边界与单位 | Product 与核算任务 |
| 2 | BOM 导入 | BOM 文件/表格 | BOMItem 列表、解析问题清单 |
| 3 | 工序与活动数据 | 工序链、设备、活动量、期间、来源 | Process 与 ActivityData |
| 4 | 因子匹配（AI 候选 + 人工确认） | 物料/工序上下文、候选列表 | Mapping（确认记录 + 依据） |
| 5 | 核算运行 | 输入快照、规则版本、分摊方法 | CalculationRun（结果 + 指纹） |
| 6 | 结果分析 | 核算结果 | 总量/分项、排序、对比、敏感性 |
| 7 | 数据包导出 | 结果 + 证据 + 缺口 + 字段映射 | DataPackage |

## 各视图输入输出与关键约束

| 视图 | 约束 |
| --- | --- |
| 项目 / 产品 | 核算边界与功能单位未填不得进入下一步 |
| BOM 导入 | 解析失败行必须逐行可见并可人工修正 |
| 工序与活动数据 | 缺单位或期间的活动数据只能存为草稿 |
| 因子匹配 | 必须同时呈现候选、依据、置信度；未经人工确认不得进入核算 |
| 核算运行 | 显示所用字典/规则/因子版本；运行期间输入只读 |
| 结果分析 | 与管理口径结果分区显示，不得混淆 |
| 数据包导出 | 导出前展示缺口清单与质量等级 |

## 状态与错误呈现

| 状态 | 呈现要求 |
| --- | --- |
| 加载中 | 显示阶段名与可取消性 |
| 空态 | 说明为什么空，并给出下一步动作 |
| 部分失败 | 列出失败条目与原因，不阻塞其余条目 |
| 校验失败 | 定位到具体字段，给出违规规则 |
| 冲突 | 显示冲突双方与需要人工裁决的选项 |
| 计算中/已完成 | 完成后展示结果指纹，供引用与复算 |

## 权限与脱敏提示

- 物料成本、供应商等敏感字段默认遮蔽，未授权时以占位符呈现并标注"已脱敏"。
- 每次遮蔽都不静默：界面需可见说明依据（角色/字段策略）。
- 查看与导出操作写入操作日志（合规内建：最小权限、脱敏、访问与操作日志）。

## 可访问性与中文本地化要求

- 界面文案简体中文；保留英文的仅限字段名、类型、文件名等标识符。
- 术语统一引用数据字典：物料、工序、活动数据、排放因子、核算运行、数据包。
- 关键操作可用键盘完成，焦点可见；颜色不作为唯一状态表达。
- 【待确认】最小分辨率、字体与 CJK 字体方案、是否提供高对比模式。

## 验收要点

- [ ] 七个视图可按顺序走通一条完整核算路径，且可从中断处恢复。
- [ ] 任何展示数值的视图都可展开查看其来源与指纹。
- [ ] 因子匹配视图中候选、依据、置信度三者同屏可见。
- [ ] 未授权字段全部以占位符呈现，且未授权导出被拒绝并留痕。
