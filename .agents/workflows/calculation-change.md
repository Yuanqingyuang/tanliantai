# 工作流：核算变更（最敏感流程）

> 状态：草案

适用：核算公式、排放因子取值、系统边界、单位口径、分摊方法的**任何**改动，包括"只改一个系数""只换一版因子""只调整边界描述"。本流程对应 `AGENTS.md` 规则 R2、R3、R9，任何一步缺失即视为不可合入。

## 0. 触发判定（命中任一即走本流程）

| 触发项 | 示例 |
| --- | --- |
| 公式 | 新增或修改计算表达式、换算系数、往返口径 |
| 因子 | 新增/替换/弃用排放因子，因子来源或区域或版本变化 |
| 边界 | 生命周期阶段取舍、纳入/排除的工序或投入 |
| 单位 | 单位口径、量纲换算、货币与实物口径转换 |
| 分摊 | 产量法、设备时间法、贴片点数法、多因素法的规则或参数变化 |
| 规则约束 | 校验范围、异常判定阈值、必填校验的变更 |

不适用：纯展示层文案、无口径影响的界面排版。若无法判断是否有口径影响，按"有"处理。

## 1. 依据（无依据不得开工）

- [ ] 写明依据类型：国家标准 / 行业标准 / 文献 / 实测数据 / 平台数据源
- [ ] 记录依据的**完整可核查标识**：标准号与条款、文献题录、数据源名称与版本、实测方法与时间范围
- [ ] 不编造数值、条款号、页码；无法核实的一律写「【待确认】」并注明需确认人
- [ ] 说明该依据为何适用于 PCBA-SMT 场景（而非其他行业口径）
- [ ] 说明改动前后结论差异方向与量级（若暂无法给量级，写明"待复算后补充"）

## 2. 登记表更新（必须同批完成）

| 登记表 | 更新内容 |
| --- | --- |
| [`knowledge/formulas/formula-register.md`](../../knowledge/formulas/formula-register.md) | 公式标识、表达式、变量定义、单位、适用边界、依据来源、生效版本、变更说明 |
| [`knowledge/emission-factors/factor-register.md`](../../knowledge/emission-factors/factor-register.md) | 因子标识、数值、单位、来源、区域、版本、适用工序、有效期、替代关系 |
| [`knowledge/README.md`](../../knowledge/README.md) | 术语或口径变化（若涉及） |
| [`contracts/README.md`](../../contracts/README.md) | 若实体字段（EmissionFactor / CalculationRun / DataPackage）随之变化 |

未登记的因子或公式**不得**在实现中直接使用；禁止硬编码"临时系数"。

## 3. 因子四重校验

因子启用前逐项确认并留痕：

| 校验 | 要点 |
| --- | --- |
| 来源 | 是否有可核查出处；是否与工序活动类型匹配 |
| 单位 | 与活动数据单位是否一致；换算链是否显式登记 |
| 区域 | 是否与生产地/电网区域匹配；不匹配时是否说明替代理由 |
| 版本 | 版本号与生效期是否正确；旧版本是否标记淘汰而非删除 |

四重校验记录以**因子快照**形式随计算留档：核算结果必须能追溯到当时使用的因子版本。

## 4. 对照案例复算

- [ ] 选取对照案例：至少覆盖本次改动影响的工序类型（含一个未受影响的对照案例）
- [ ] 案例数据来源：优先 [`tests/fixtures/README.md`](../../tests/fixtures/README.md) 的基准数据；不得使用未脱敏企业数据
- [ ] 记录"改动前 / 改动后"结果对照：总量、分层项、单位、差异率、差异原因
- [ ] 分摊方法变更时，补充敏感性分析：不同分摊口径下的结果区间
- [ ] 复算记录必须可重现：写明输入、参数、命令或操作步骤
- [ ] 若差异超出预期，回到第 1 步复核依据，不得"调整案例凑结果"

## 5. 版本与指纹

- [ ] 数据包规范版本是否变化（口径变化通常需要升版）
- [ ] 因子版本 / 规则版本是否变化，并在数据包中显式携带
- [ ] 结果指纹变化说明：哪些输入的指纹会变、为什么必须变
- [ ] 历史结果处理策略：保留旧版本可复算，或声明重算范围
- [ ] 变更记录写入 `CHANGELOG.md` 与交付报告

## 6. 人工确认与评审

| 角色 | 确认内容 |
| --- | --- |
| 核算规则负责人 | 依据是否充分、公式与因子取值是否正确、边界是否恰当 |
| 数据包负责人 | 数据包字段、缺口与质量等级、指纹与修改记录是否自洽 |
| 项目负责人 | 是否影响已交付成果与对外承诺 |
| 指导教师 | 口径与标准理解存在争议时的裁定（标注「待确认」并请其确认） |

评审按 [`review.md`](review.md) 的"知识与依据审查"视角执行。

## 7. 退出条件检查清单

- [ ] 依据已记录且可核查
- [ ] 两张登记表已更新且与实现一致
- [ ] 因子四重校验记录（因子快照）已留档
- [ ] 对照案例复算完成，差异有解释
- [ ] 版本号与结果指纹变化已说明
- [ ] 人工确认记录已留痕（谁、何时、确认了什么）
- [ ] 交付报告按 [`templates/delivery-report.md`](../templates/delivery-report.md) 完成
