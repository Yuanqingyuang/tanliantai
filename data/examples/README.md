# 公开示例数据（data/examples）

> 状态：首期骨架

本目录只存放**可公开的演示项目与示例数据**，用于跑通流程、演示界面与编写文档。
这里的数据不是核算基准（基准在 [../../tests/fixtures/README.md](../../tests/fixtures/README.md)），
但必须与基准使用同一套字段约定，避免演示与验收出现两套口径。

## 一、示例来源

| 来源 | 说明 | 使用限制 |
| --- | --- | --- |
| 公开行业资料 | 公开的 PCBA-SMT 工艺描述、通用物料分类 | 引用时注明出处，数值不得当作排放因子使用 |
| 自建脱敏样例 | 按真实结构构造、但内容全部替换的样例 | 必须经脱敏检查并留下声明 |
| 标准与文献摘录 | 公开发布的标准条文与文献结论 | 只摘录可公开内容，页码与条款【待确认】前不得引用 |

排放因子的正式数值只能来自 `knowledge/emission-factors/factor-register.md`，
示例数据里出现的因子引用必须指向该登记表，不得自造数值。

## 二、脱敏要求

1. 料号统一改为可识别为示例的编号（例如 `DEMO-` 前缀），不得保留真实料号。
2. 删除客户名、供应商名、项目代号、订单号、报价与任何人员信息。
3. 工艺参数允许保留量级，但不得精确到可反查具体产线的程度。
4. 图片与截图同样属于数据：图中不得出现料号、客户名与价格。
5. 每份示例数据集必须带一份脱敏声明，写明"替换了什么、保留了什么、由谁确认"。

**真实企业 BOM 与工艺数据属敏感数据，不得提交进 Git**，处理方式见
[../../.agents/policies/data-security.md](../../.agents/policies/data-security.md)。

## 三、字段与命名约定

| 项目 | 约定 |
| --- | --- |
| 目录 | 一个演示项目一个目录，名称用 `小写英文 + 短横线`，与其中的说明文件同名 |
| 说明文件 | 每个目录下必须有 `README.md`，写明案例名、产品与功能单位、边界、数据来源与脱敏声明 |
| 数据文件 | 使用 [../templates/README.md](../templates/README.md) 定义的导入模板格式 |
| 编码与换行 | UTF-8 无 BOM、LF 换行 |
| 字段命名 | 与数据字典一致；单位单独成列，不写在字段名里 |
| 空值 | 统一留空，不使用 `N/A`、`-`、`无` 等混用写法 |

## 四、如何被引用

| 引用方 | 引用方式 |
| --- | --- |
| 文档 | 用仓库相对路径链接到具体示例目录或其说明文件 |
| `tests/fixtures/` | 可基于本目录样例派生基准，但派生后须独立声明基准版本与期望结果 |
| `modules/` 文档 | 用本目录样例说明导入格式与字段含义 |
| 演示与答辩 | 只使用本目录数据；禁止临时替换为真实企业数据 |

引用时禁止复制粘贴数值到文档正文，避免文档与数据两处不一致。

## 五、维护约定

- 新增示例须同时提交：数据文件 + `README.md` + 脱敏声明。
- 修改示例时须检查是否有测试或文档引用它，并同步更新引用方。
- 删除示例前先确认全仓库无引用；已用于验收报告的样例不得删除。
- 本目录内容由 [../../tools/README.md](../../tools/README.md) 中规划的脱敏检查工具做提示性校验。
