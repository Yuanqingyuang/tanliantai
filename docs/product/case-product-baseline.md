## 6. 运输排放（对齐 T-0007 TBD-AC-03）

| 项 | 定义 |
|---|---|
| **纳入范围** | 来料运输：供应商工厂 → 我方仓库 |
| **运输方式** | 公路运输（卡车）为主，必要时含海/空运 |
| **距离来源** | 供应商地区 → 工厂所在城市中心距离（高德/百度地图 API） |
| **排放因子** | 中国公路货运平均因子（参考 CLCD/生态环境部指南） |
| **计算公式** | E_trans = Σ(距离_km × 质量_t × EF_kgCO2e/t·km) |
| **数据版本** | v2026-11-20（冻结版本） |
