# 0002. 本地 Web 工作台与研究原型技术栈建议
> 状态：提议
> 日期：2026-10-27
> 提议整理：Codex，依据项目负责人“重新设计详细技术方案”的任务；决策与复核人：项目团队、指导教师【待确认】。

## 背景与问题

原计划书提出 Vue/TypeScript、Python/FastAPI、MySQL 和 FAISS 等轻量检索方案；现有 ADR 索引仍将语言、数据库、应用形态列为待决。本次将建议具体化，供团队评审，不宣告技术栈已批准，不修改运行环境或正式契约。

一年期研究需要同时支撑 Excel 数据准备、规则与语义匹配对照、确定性计算和数据包回放，且企业数据应在本地或内网处理。应优先降低维护成本，把研究投入集中在数据质量与实验。

## 备选方案

| 决策 | 方案 | 优点 | 代价或不采用理由 |
| --- | --- | --- | --- |
| 应用形态 | 本地/内网 Web 工作台（推荐） | 浏览器交互，一套前后端支持个人演示与内网协作 | 仍需安装和维护后端；离线能力要验证 |
| 应用形态 | Electron/Tauri 桌面壳 | 可提供安装包和桌面入口 | 增加壳层、Python 进程管理和跨平台发布工作 |
| 应用形态 | 公网 SaaS | 访问便利 | 需要额外的数据出域、租户隔离和运营能力 |
| 前端 | Vue 3 + TypeScript（推荐） | 延续原计划书，适合表格、表单和审核工作流 | 团队仍需统一组件与接口规范 |
| 前端 | React + TypeScript | 也能完成需求，生态可用 | 当前无证据表明切换能带来与迁移成本相称的收益 |
| 后端 | Python + FastAPI（推荐） | 数据处理、模型实验和业务接口统一语言 | 需隔离耗时任务，不能直接占用请求处理线程 |
| 后端 | Java/Spring Boot + Python 模型服务 | 企业应用生态成熟 | 本项目会增加语言与服务间接口成本 |
| 存储 | PostgreSQL（推荐） | 关系约束、NUMERIC 数值与 JSONB 快照适合本项目数据组织 | 相比原 MySQL 设想有学习成本，JSONB 本身不保证防篡改 |
| 存储 | MySQL | 延续原设想，DECIMAL 与 JSON 也可满足核心需求 | 若团队更熟悉，可在评审后采用；不能声称技术上不可行 |
| 存储 | SQLite | 单机安装简单 | 首期不承担双数据库兼容测试；仅未来独立离线版再评估 |
| 检索 | 本地嵌入模型 + 精确相似度检索（推荐起点） | 适合小规模实验、易复现、无需独立向量服务 | 扩容后需测量延迟和内存 |
| 检索 | FAISS / pgvector | 可在规模增大时建立索引 | 增加索引更新与一致性管理；达到性能瓶颈再引入 |

## 决策

以下为当时的建议，后续确认见同目录申报确认记录。

采用模块化单体：Vue 3 + TypeScript + Vite + Element Plus + Pinia + ECharts；Python + FastAPI + Pydantic + SQLAlchemy + Alembic；PostgreSQL；本地文件证据仓库；Python Decimal 确定性核算；本地 Sentence Transformers 嵌入与规则融合检索。BGE-M3 作为中英混合检索的候选基线模型，具体版本与运行资源经实验确定。生成式大模型为可关闭的解释增强能力。

开发环境延续现有容器路线，部署优先 Linux/WSL2 + Docker Compose；依赖选择当时仍受支持且通过兼容性验证的稳定版本，锁定依赖和镜像。现有 Python 3.12 仅作首次兼容性验证起点，不宣称为最新版本。

数据包建议以 ZIP 容器承载 JSON 权威数据、CSV 明细、可读报告、证据清单与哈希；具体 schema、精度、指纹规范属于后续独立契约与 ADR 工作，本文件不批准这些细节。

## 理由

将表格处理、核算与实验统一在 Python 中，减少业务规则重复实现；通过浏览器完成复杂审核交互；以关系数据库维护实体、版本和确认关系。先证明完整业务闭环和四组实验可运行，再决定是否增加索引服务、任务队列或桌面壳。

## 后果与代价

- MySQL 改为 PostgreSQL 是本次新建议；当前无业务数据库，无需搬迁已有企业数据，但应评估团队学习成本。
- 模型向量、候选缓存必须能根据模型版本与知识库版本失效重建。
- 企业数据和日志只在受控运行目录保存，禁止进入 Git；外部 AI 默认关闭。
- 哈希用于一致性校验，不等于电子签名或第三方认证。
- 确定性不仅依赖 Decimal，还依赖精度、舍入、运算顺序、规范序列化和版本快照。
