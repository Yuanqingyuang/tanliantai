# 版本规划与里程碑

> 状态：首期骨架
> 子目录：版本规划、任务与里程碑

本目录维护项目两年周期（2026年10月—2028年9月，共24个月）的阶段目标、交付物与验收口。周期依据2026-10-28用户明确修正；当前申报安排见[两年图示修订任务](2026-10-28-two-year-figures-task.md)。第一年形成核心原型与中期成果，第二年开展集成、正式实验、场景复核与结题。

运行中任务见[任务台账](tasks.md)，交付物分解见[WBS](wbs.md)。WBS 保留远程任务编号；其五阶段时间需另行对齐本页八阶段两年申报安排，确认人为项目负责人。

## 二、分阶段任务

### 阶段一 标准与需求核对（2026.10—12）

袁青扬统筹标准、文献与需求，赵天志核对术语、单位与核算方法，陈霖梳理PCBA-SMT工序，全员组织数据需求与四组实验指标。先开展T-0010 PostgreSQL依赖、精度、事务、并发、迁移与备份恢复适配，形成环境和验证记录。依据沿用[文献登记](../../knowledge/references/bibliography.md)、[术语表](../../knowledge/domain/glossary.md)、[单位换算](../../knowledge/domain/units-and-conversions.md)及[公式库](../../knowledge/formulas/README.md)。

### 阶段二 数据字典与系统架构（2027.01—03）

袁青扬、陈霖组织[数据字典](../../modules/data_dictionary/README.md)，王靖锴组织[数据包规范](../../modules/data_package/README.md)，全员评审[架构](../architecture/README.md)与[接口契约](../../contracts/README.md)。石凌云设计[导入模板](../../data/templates/README.md)与Web基础流程，建立四角色权限、会话、HTTPS和审计基础。

### 阶段三 标注样本与匹配方法（2027.04—06）

陈霖组织不少于1000条计划匹配样本、规则/语义/融合方法与人工确认流程；石凌云参与标注、分组评测和操作记录。样本按来源分组划分，独立测试部分冻结，调优及预实验使用开发集。形成标注规范、匹配基线与消融预实验记录。

### 阶段四 核心原型与中期评审（2027.07—09）

赵天志完成[确定性核算原型](../../modules/calculation/README.md)及四类分摊候选，陈霖组织AIProvider与本地模型适配，王靖锴衔接冻结快照和结果指纹，石凌云集成核心操作界面。袁青扬统筹第一年研究报告与中期评审，演示字典、候选、人工确认和计算的核心链路。

### 阶段五 系统集成与碳数据包（2027.10—12）

王靖锴组织数据包导出、证据清单、审计链和隔离回放；石凌云组织内网多用户集成、会话、服务端权限、并发与恢复测试。全员核对版本一致性和真实数据本地处理要求，形成集成版本与系统测试记录。

### 阶段六 四组对照实验（2028.01—03）

按[验收评测](../../tests/acceptance/README.md)组织实验A匹配效果、B公共资源分摊、C流程效率、D独立复算。分别由陈霖、赵天志、石凌云、王靖锴负责对应记录，袁青扬统筹研究报告。记录来源、环境、参数、版本和操作过程，形成对照、消融、适用条件与误差分析。

### 阶段七 稳健性与场景验证（2028.04—06）

全员复核来源变化、缺失资料、分摊情景和多用户并发下的表现，补充断网、权限与恢复验证。经企业正式授权且数据、计量条件具备时开展本地真实案例补充验证；新增来源样本和测试结果独立登记。同步整理软著申请材料及报告修订稿。

### 阶段八 成果固化与结题（2028.07—09）

袁青扬统筹软件著作权、研究报告、论文竞赛与结题，赵天志复核方法和实验，陈霖归档标注与案例，王靖锴整理数据包及商业计划书，石凌云完善部署、用户说明与演示。冻结字典/规范V1.0、可运行原型及可复现实验包，整理实际登记、评审与成果凭证。

## 五、风险与应对

| 风险 | 可能后果 | 应对 |
| --- | --- | --- |
| 拿不到真实企业数据 | 无法做外部验证 | 以公开资料与自建脱敏案例为主，把真实数据当"争取项"；提前联系意向企业 |
| 标准条文理解偏差 | 公式与边界错误 | 逐条登记来源，关键条目由指导教师复核 |
| 因子口径不统一 | 结果不可复核 | 四重校验 + 因子快照 + 版本化 |
| 技术选型反复 | 返工 | 尽快用 ADR 定选型，先做数据字典与规范等相对独立的产出 |
| AI 效果不达标 | 实验 A 结论不利 | 实验设计先于开发；若 AI 无效则如实报告，把确定性链路与数据字典作为主成果 |
| 排期与课业冲突 | 里程碑延期 | 每阶段留缓冲；跨阶段任务（文档维护）持续进行 |
