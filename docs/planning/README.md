## 五、风险与应对

| 风险 | 可能后果 | 应对 |
| --- | --- | --- |
| 拿不到真实企业数据 | 无法做外部验证 | 以公开资料与自建脱敏案例为主，把真实数据当"争取项"；提前联系意向企业 |
| 标准条文理解偏差 | 公式与边界错误 | 逐条登记来源，关键条目由指导教师复核 |
| 因子口径不统一 | 结果不可复核 | 四重校验 + 因子快照 + 版本化 |
| 技术选型反复 | 返工 | 尽快用 ADR 定选型，先做数据字典与规范等相对独立的产出 |
| AI 效果不达标 | 实验 A 结论不利 | 实验设计先于开发；若 AI 无效则如实报告，把确定性链路与数据字典作为主成果 |
| 排期与课业冲突 | 里程碑延期 | 每阶段留缓冲；跨阶段任务（文档维护）持续进行 |
