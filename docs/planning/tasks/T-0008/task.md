## 2. 目标

- 确定 MVP 第一个验证对象：具体某款 PCBA 产品
- 定义功能单位、系统边界、生命周期阶段纳入范围
- 明确物料清单（BOM）模板与工序路线
- 与 T-0004/T-0005/T-0007 基线交叉检查术语/单位/指标覆盖
- 形成案例产品基线文档，供 T-0011 数据字典、T-0015 导入模板、T-0016 数据采集使用

## 3. 范围

- 本次要做：
  - 选定 1 款 PCBA 产品（型号、层数、尺寸、工艺路线）
  - 定义功能单位（如 1 片 / 1 m² / 1000 点）
  - 定义系统边界：cradle-to-gate（含来料运输）或 cradle-to-grave
  - 生命周期阶段纳入：原料获取、制造（T-0005 12 道工序中哪些）、来料运输
  - BOM 模板：字段、单位（对齐 UNIT-xxx）、质量等级要求
  - 工序路线：使用 T-0005 12 道工序中的哪些、顺序、公用工程
  - 交叉检查：术语（TERM-xxx）、单位（UNIT-xxx）、验收指标（A-01~D-03）是否覆盖
- 本次明确不做：
  - 不采集企业真实数据（属 T-0016）
  - 不决定第三方认证要求（属后续）

## 4. 非目标

- 不编写业务代码
