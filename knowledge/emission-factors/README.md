# 排放因子库说明（emission-factors）

> 状态：首期骨架

本子库登记产品碳足迹核算所用的排放因子。**当前仓库暂无已确认的因子数据**：本子库首期只建立字段、来源优先级与流程规则，因子值以官方发布为准，须人工复核后入库。

## 1. 因子必须包含的字段

| 字段 | 含义 | 必填 | 取值要求 |
| --- | --- | --- | --- |
| 因子 ID | `EF-<类别>-<序号>` | 是 | 唯一、不复用 |
| 因子名称 | 中文名与计量对象 | 是 | 与来源文档表述一致 |
| 因子值 | 单位活动数据的排放量 | 是 | 必须来自来源文档，禁止估算填写 |
| 单位 | 分母单位与被除对象 | 是 | 如 kgCO₂e/kWh、kgCO₂e/kg，须可校验 |
| 区域/电网 | 地理或电网适用范围 | 是 | 电力因子必须写明电网分区 |
| 年份/版本 | 因子发布年份或版本号 | 是 | 与核算期匹配性须核对 |
| 来源 | 发布机构与文档名 | 是 | 无来源不得入库 |
| 适用对象 | 可用于哪些活动数据/工序 | 是 | 需与工序、物料类型匹配 |
| 质量等级 | 数据质量分级 | 是 | 见 `../README.md` 来源分级 |
| 审核状态 | draft / review / verified / deprecated | 是 | 未 verified 不得进入正式核算 |
| 备注 | 适用限制与已知问题 | 否 | 记录口径差异与替代关系 |

## 2. 来源优先级

| 优先级 | 来源类型 | 说明 |
| --- | --- | --- |
| P1 | 国家标准或官方发布 | 主管部门、国家统计或标准体系正式发布的数据 |
| P2 | 权威数据库 | 有方法学文档、可追溯版本的数据库 |
| P3 | 文献 | 同行评议文献中的因子，须记录边界与方法 |
| P4 | 企业实测 | 企业计量或检测数据，须记录计量方式与期间 |
| P5 | 估算 | 仅在无以上来源时使用，必须登记估算方法与不确定性 |

要求：同一用途存在更高优先级来源时，不得使用更低优先级来源；若因口径匹配必须降级使用，须在备注中写明理由并经复核。

## 3. 禁用做法

1. **无来源因子**：来源栏为空或写「网络」「经验值」的因子一律不得入库。
2. **来源不明的网络值**：博客、论坛、未署名截图、AI 生成文本中的数值不得作为因子。
3. **跨区域直接套用**：其他电网、其他国家或地区的因子直接用于本地活动数据。
4. **跨年份混用**：因子年份与核算期不匹配且未记录差异影响。
5. **单位口径不一致**：因子分母单位与活动数据单位不一致时不得直接相乘（见 `../domain/units-and-conversions.md`）。
6. **未复核即使用**：`draft`/`review` 状态的因子不得进入正式核算结果。
7. **代填企业数据**：用行业均值静默替换缺失的企业实测值。

## 4. 更新与废弃流程

1. **新增**：录入 → 标注来源与适用对象 → 提交复核 → 复核通过后状态改为 `verified`。
2. **更新**：来源发布新版本时，新增行并保留旧行；旧行标记 `deprecated`，备注指向新因子 ID。
3. **废弃**：来源失效、口径不再适用或被更高优先级来源取代时标记 `deprecated`；**禁止删除**，以保证历史 `CalculationRun` 可复算。
4. **变更留痕**：每次变更在 `factor-register.md` 的变更记录追加一行；影响结果口径的变更须记录到 `../docs/decisions/README.md`（如已建立）。
5. **版本联动**：因子版本变化会改变结果指纹，重算时必须同时更新 `CalculationRun` 的规则版本与输入快照。
