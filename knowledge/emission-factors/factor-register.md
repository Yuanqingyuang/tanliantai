# 因子登记表（factor-register）

> 状态：首期骨架

本表是排放因子的唯一权威清单。**当前仓库暂无已确认的因子数据**，因此本表只提供字段说明与占位示例：示例行的因子值一律写「示例，待替换」，来源一律写「占位」。真实因子须以官方发布为准，经人工复核后入库，并遵守 `README.md` 的来源优先级与禁用做法。

## 1. 登记字段说明

| 字段 | 含义 | 填写要求 |
| --- | --- | --- |
| 因子 ID | `EF-<类别>-<序号>` | 类别码：ELEC 电力、FUEL 燃料、WAT 水、GAS 气体、AUX 辅材、PKG 包装、TRA 运输、MAT 上游材料 |
| 因子名称 | 中文名 + 计量对象 | 与来源文档表述一致 |
| 因子值 | 单位活动数据的排放量 | 必须来自来源文档；未确认时写「示例，待替换」 |
| 单位 | 分母与被除对象 | 如 kgCO₂e/kWh、kgCO₂e/kg |
| 区域/电网 | 适用范围 | 电力因子必须写电网分区 |
| 年份/版本 | 发布年份或版本 | 须与核算期匹配 |
| 来源 | 发布机构与文档名 | 无来源不得入库；占位时写「占位」 |
| 适用对象 | 可用于哪些活动数据/工序/物料 | 需与工序、物料类型匹配 |
| 质量等级 | 数据质量分级 | 见 `../README.md` 来源分级 |
| 审核状态 | draft / review / verified / deprecated | 首期全部为 draft |

## 9. 入库前检查清单

1. 因子值是否逐字来自来源文档，且来源文档已登记在 `../references/bibliography.md`？
2. 单位分母是否与活动数据的单位口径一致？
3. 区域与年份是否与核算对象匹配？
4. 是否存在更高优先级的可用来源？
5. 是否已由人工复核并签注，状态改为 `verified`？
