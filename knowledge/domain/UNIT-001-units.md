# 单位与换算表（UNIT-xxx 规范）

> 状态：第 2 周主体建设中（基于 units-and-conversions.md 补全标准值与版本）
> 规范：UNIT-<三位序号>-<域标识>
> 域标识：ENG=能源、MAS=质量、CNT=计数、ARE=面积、VOL=体积、EQU=当量、PWR=功率、TIM=时间、PRJ=项目自定义

## 结构定义

| 字段 | 说明 | 必填 |
|------|------|------|
| ID | UNIT-<三位序号>-<域> | 是 |
| 物理量 | 中文名 | 是 |
| 标准符号 | SI/通用符号 | 是 |
| 量纲 | 质量/长度/时间/温度/物质的量/电流/发光强度 | 是 |
| 基准单位 | 核算内部统一基准单位 | 是 |
| 常用别名 | 业务常见写法 | 否 |
| 换算关系 | 到基准单位的倍率/公式 | 是 |
| 换算性质 | 定义性 / 非定义性(需登记来源) | 是 |
| 来源/版本 | 非定义性换算的来源编号+版本 | 非定义性必填 |
| 口径陷阱 | 易混淆点、禁忌用法 | 否

## 换算登记强制规则（同 units-and-conversions.md）

1. **非定义性换算必须登记来源**：在 ../references/bibliography.md 有对应条目，写明适用条件与版本。
2. **保留原始单位**：ActivityData 同时保存原始数值+原始单位；换算值作为派生字段，禁止覆盖原始值。
3. **单位一致性强制校验**：核算前校验 ActivityData.unit 与 EmissionFactor.unit 相容性；不相容即拒绝计算报错。
4. **单位口径变更即破坏性变更**：须记录版本，历史 CalculationRun 复算按当时版本。
5. **禁止静默换算**：换算过程必须在证据链留痕(原始值→汇率/系数→换算值→来源)。
