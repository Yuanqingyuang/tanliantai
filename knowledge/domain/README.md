# 领域知识子库（domain）

> 状态：首期骨架

## 1. 范围

本子库收录 PCBA/SMT 电子制造**产品碳足迹**核算所需的领域常识与口径约定，不收录因子数值与核算结果。

- 属于本子库：术语定义、工序链与设备、单位与换算、活动数据可得性与质量隐患、系统边界建议。
- 不属于本子库：具体排放因子值（见 `../emission-factors/factor-register.md`）、公式定义（见 `../formulas/README.md`）、文献条目（见 `../references/bibliography.md`）。

## 3. 领域知识撰写要求

1. 每条知识必须能回答三件事：谁在用、用在核算的哪一步、写错会导致什么后果。
2. 工序与设备描述基于行业常识，**仅作工序链结构示例**；具体口径以企业实际与适用标准为准，涉及企业差异处写【待确认：需企业工艺与设备清单确认】。
3. 术语条目必须给出「易混淆点」，用于 AI 副驾驶的风险提示与人工复核要点。
4. 不确定的领域细节一律写 `【待确认：<查证对象>】`，不得凭印象补全。
5. 与标准冲突时，以 GB/T 24067-2024 及适用的现行标准为准，并在条目内记录冲突与处理结论。

## 5. 使用限制

- 本子库内容仅供内部核算与方法说明使用，**不构成合规声明**；对外交付材料的合规表述须经复核人确认。
- 工序链示例不得当作某家企业的实际工艺路线；生成数据包时必须替换为该企业登记的 Process 清单。
- 名称与型号类的设备举例不得写入示例数据中的真实客户或供应商信息。
