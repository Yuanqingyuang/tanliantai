# PCBA-SMT 工序链与设备

> 状态：第 2 周已对齐新规范（引用 TERM/UNIT/F-<域> ID）

本文描述 PCBA/SMT 电子制造的典型工序链结构，用于建立**工序级**活动数据字典与建模口径。
工序与设备为**行业常识性示例**，具体口径以企业实际工艺与适用标准为准；涉及企业差异处一律标注【待确认】。
**术语、单位、公式 ID 已对齐 \TERM-001-glossary.md\、\UNIT-001-units.md\、\ormula-register.md\。**

## 1. 工序 ID 命名建议

格式：\PCBA-<两位序号>-<英文缩写>\（对应 **TERM-307-PRJ**）

- 序号反映工序在流程中的顺序，步长 10 预留插入位（如 01、02 …）。
- 英文缩写用 3 个大写字母，取工序英文名的首字母组合，避免与设备型号混淆。
- 工序组（如「贴装段」「焊接段」）用 \PCBA-G-<组名缩写>\，仅用于汇总展示，不用于活动数据登记。
- ID 一旦投入核算不得复用或改写语义；工艺变更新增工序时分配新 ID，旧 ID 标记为 deprecated。

## 4. 工序级建模的边界建议

1. **默认边界**：cradle-to-gate——原材料获取与来料运输（数据可得时）+ 生产制造（本文 12 道工序）至成品入库。对应 **TERM-004-BAS(系统边界)**。
2. **纳入判定**：与产品直接相关的工序必须纳入；公用工程按第 3 节分摊后纳入。分摊方法需登记 **TERM-309-PRJ(分摊系数)** 与版本。
3. **排除项须显式登记理由**：如办公区、生活设施、基建与资本品等；是否排除【待确认：需按 GB/T 24067-2024 相关要求与客户模板确认】。
4. **粒度一致性**：可选用「工序级」或「工序组级」，但同一企业同一产品线前后必须一致；变更粒度视为破坏性变更，须记录版本。
5. **边界变更即不可比**：跨版本比较前必须核对 \CalculationRun\ 中的边界与规则版本。
6. **禁止整厂平摊**：任何共因资源都必须有登记过的分摊方法与依据（见 \../formulas/allocation-methods.md\，对应 **F-AL-001~004**）。
