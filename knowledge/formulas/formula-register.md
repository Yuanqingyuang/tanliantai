# 公式登记表（formula-register）

> 状态：第 2 周主体建设中（补全 GB/T 24067-2024 条款号、GWP 版本）
> 规范：F-<域>-<三位序号>
> 域标识：CF=碳足迹核算、AL=分配分摊、TR=运输、OT=其他
> **本表只登记表达式与来源，不写任何具体系数数值**；系数一律从 ../emission-factors/factor-register.md 或登记参数取值

## 1. 登记字段说明

| 字段 | 含义 | 填写要求 |
|------|------|----------|
| 公式 ID | F-<域>-<三位序号> | 唯一、不复用 |
| 名称 | 公式中文名 | 与来源文件标题一致 |
| 表达式 | 结构化表达式 | 只含变量，不含常数系数 |
| 变量 | 主要变量与含义 | 完整变量表见来源文件 |
| 单位 | 结果单位 | 与变量单位一致 |
| 适用条件 | 可使用的前提 | 不满足即不得使用 |
| 来源/依据 | 标准、文献或依据 | 无法确认写【待确认：需查证的对象】 |
| 版本 | <主>.<次> | 语义变更递增主版本 |
| 审核状态 | draft / review / verified / deprecated | 首期全部为 draft |
| 变更记录 | 日期、变更人、变更摘要 | 追加，不覆盖 |
