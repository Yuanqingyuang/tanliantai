# 公式库说明（formulas）

> 状态：首期骨架

本子库登记「链碳台」核算所用的全部公式。公式是确定性核算发动机的唯一计算依据：**未登记的公式不得用于正式核算**。

## 1. 公式登记规则

1. 每个公式必须有唯一 ID、名称、表达式、变量表（符号/含义/单位/来源）、适用条件、不适用情形与版本，并同步登记到 `formula-register.md`。
2. 公式只能引用已登记的变量与实体字段；引用了未登记的量视为不完整公式，不得进入 `verified`。
3. 公式中**不得硬编码数值系数**（如损耗率、负载率、GWP 值）。系数一律以参数或因子形式从登记表取值。
4. 公式来源栏填标准、文献或依据名称；无法确认时写【待确认：需查证的来源】，不得留空。
5. 公式语义变更（改变量含义、改边界、改分母）必须新增版本，禁止原地改写。

## 2. 公式 ID 规则

格式：`F-<域>-<三位序号>`，序号按登记顺序分配，不复用、不回收。

| 域代码 | 含义 | 文件 |
| --- | --- | --- |
| CF | 产品碳足迹核算 | `carbon-footprint.md` |
| AL | 资源分摊 | `allocation-methods.md` |
| DQ | 数据质量与缺口（预留） | 【待确认：是否建立】 |

示例：`F-CF-001`、`F-AL-003`。

## 3. 变量命名约定

| 约定 | 说明 | 示例 |
| --- | --- | --- |
| 主符号 | 大写或短驼峰，表示物理量或业务量 | `E` 排放量、`AD` 活动数据、`EF` 排放因子、`Q` 产量 |
| 下标 | 小写字母或数字，表示索引 | `i` 工序、`j` 物料、`k` 能源或资源、`g` 温室气体、`p` 产品、`t` 期间 |
| 单位后缀 | 不写入符号，统一在变量表中显式声明 | `AD_{i,k}` 单位为「kWh」「kg」等 |
| 专用量 | 分摊与基准量使用固定符号 | `AF` 分摊系数、`FU` 功能单位、`N` 贴片点数、`T` 设备时间 |
| 禁止 | 同一符号在不同公式中表示不同量；单位隐含在文字描述中 | — |

## 4. 适用条件与失效条件

每个公式登记时必须同时给出：

- **适用条件**：数据粒度（工序级/物料级）、边界（cradle-to-gate 等）、计量方式（实测/估算）满足要求才能使用。
- **不适用情形**：数据缺失、口径不一致、跨边界引用等情况下禁止使用，必须改为登记数据缺口。
- **失效触发**：出现下列任一情形，公式结果必须重算并记录版本——系统边界变更、单位口径变更、分摊方法变更、排放因子版本变更、GWP 版本变更、功能单位变更。

## 5. 版本规则

1. 版本号采用 `v<主>.<次>`，从 `v1.0` 起。
2. 编辑性修改（措辞、格式、补充说明）递增次版本；语义修改（变量含义、公式结构、适用条件收紧或放宽）递增主版本。
3. 公式版本必须写入 `CalculationRun` 的「规则版本」字段；结果指纹随之变化。
4. 废弃公式保留在登记表中并标记 `deprecated`，注明替代公式 ID。
