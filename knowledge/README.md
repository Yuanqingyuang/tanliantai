# 链碳台（CHAINPCF）碳核算知识库总述

> 状态：首期骨架

## 1. 知识库定位

本目录是「链碳台 CHAINPCF（Chain Product Carbon Footprint）」的碳核算知识库，为 AI 副驾驶、确定性核算发动机与结构化碳数据包三类产品能力提供**可追溯、可复核、可版本化**的知识底座。

- 一句话定位：AI 辅助的 PCBA-SMT 工序级碳数据字典、核算工具与数据包。
- 核算对象：**产品碳足迹**（PCBA/SMT 电子制造场景）。
- 主要依据：GB/T 24067-2024《温室气体 产品碳足迹 量化要求和指南》（2024.08 发布，2024.10.01 实施）。
- 当前仓库状态：仅有资料（`docs/product` 下的项目计划书与答辩 PPT、`resources/` 下的 logo），**尚无代码、暂无已确认的因子数据**。因此首期只建立登记框架与规则，不写入任何未经验证的因子数值。

## 2. 知识来源分级

| 等级 | 名称 | 说明 | 示例 | 在核算中的可用范围 |
| --- | --- | --- | --- | --- |
| L1 | 标准 | 国家标准、国际标准正文及其规范性附录 | GB/T 24067-2024 | 方法与规则的第一依据 |
| L2 | 政策与官方文件 | 主管部门发布的意见、实施方案、试点通知 | 发改环资〔2023〕1529 号 | 边界、口径与合规要求的依据 |
| L3 | 学术文献与权威数据库方法学 | 经同行评议的论文、数据库方法学文档 | 【待确认：具体文献与数据库方法学文档】 | 可作补充方法，必须注明原始出处 |
| L4 | 行业数据 | 行业协会、设备厂商、供应链公开统计 | 【待确认：具体行业报告】 | 仅作背景与合理性检查，不单独作为核算依据 |
| L5 | 企业实测 | 企业计量表、工单、MES/ERP 导出记录 | 电表读数、工时记录、领料单 | 活动数据的首选来源，须登记数据质量等级 |

来源等级由知识库维护人初判，审核人在标注 `verified` 前复核；等级判定存疑时按较低等级处理。

## 3. 审核状态定义

| 状态 | 中文 | 含义 | 可进入正式核算？ |
| --- | --- | --- | --- |
| draft | 草案 | 已录入但未经复核，含全部 AI 生成内容 | 否 |
| review | 待复核 | 已提交复核，复核人尚未签注 | 否 |
| verified | 已复核 | 由人工复核并签注来源与适用范围 | 是 |
| deprecated | 已废弃 | 被新版本取代或来源失效，保留以追溯历史计算 | 否（仅用于历史复算） |

状态流转固定为 `draft → review → verified → deprecated`。任何条目**不得**从 `draft` 直接跳到 `verified`；`deprecated` 条目禁止删除，只能被新条目取代。

## 4. 版本与变更规则

1. 每个文件第二行固定为 `> 状态：首期骨架`；条文级状态写在表格的「审核状态」列。
2. 登记表类文件（公式、因子、来源）必须含「版本」与「变更记录」字段；变更时新增行或追加记录，**不覆盖历史**。
3. 破坏性变更（口径、单位、边界、公式语义、分摊方法）必须先登记再更新引用，并在同一改动内同步所有引用方。
4. 影响产品行为的重大决策记录到 `../docs/decisions/README.md`（如已建立），知识库只保留结论与链接。
5. 每次修订在文件末尾「变更记录」小节追加一行：日期、变更人、变更摘要；日期未定前写【待确认：日期与变更人】。

## 5. 硬性规则（与知识库交互时必须遵守）

1. **无来源不收录**：术语、公式、因子、来源条目都必须写明来源；写不出出处的一律标注 `【待确认：需查证的对象】`，且不得进入 `verified`。
2. **AI 生成内容先标草案**：AI 副驾驶只给候选与依据，不产生正式核算数值；AI 产出的条文一律先标 `draft`，经人工复核并签注来源后才能改为 `verified`。
3. **【待确认】标注格式**：写作 `【待确认：<需要谁确认 / 查哪份标准 / 查哪份文件>】`；禁止只写「待确认」而不指明对象。
4. **不写入未确认的数值**：因子值、系数一律不写具体数字，改为在 `emission-factors/factor-register.md` 登记占位行；纯定义性换算法则（如时间、质量、能量单位换算）除外，但须在 `domain/units-and-conversions.md` 登记。
5. **同一输入 → 同一结果**：知识库条目必须能被 `CalculationRun` 的「规则版本」字段引用；所有数值计算只能由确定性核算发动机执行。
6. **原始数据不可丢**：换算必须保留原始单位与原始数值，换算规则与来源登记后方可使用。
