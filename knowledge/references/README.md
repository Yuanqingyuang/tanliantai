# 来源登记规则（references）

> 状态：首期骨架

本子库登记知识库中用到的全部来源。**没有登记来源的条文、公式与因子不得进入 `verified`**。来源清单见 `bibliography.md`。

## 1. 文献条目字段

| 字段 | 含义 | 必填 | 填写要求 |
| --- | --- | --- | --- |
| 编号 | `R-<三位序号>` | 是 | 唯一、不复用 |
| 类型 | 标准 / 政策文件 / 文献 / 数据库 / 行业报告 / 企业文件 | 是 | 单选 |
| 标题 | 文件或标准的完整名称 | 是 | 用原文名称，不缩写 |
| 发布机构 | 发布单位 | 是 | 无法确认写【待确认：需查证发布机构】 |
| 编号/标准号 | 标准号或文号 | 是 | 政策文件写发文号，标准写标准号 |
| 年份 | 发布或版本年份 | 是 | 与实施日期区分 |
| 适用范围 | 可用于哪些环节（术语/公式/因子） | 是 | 写明具体用途，避免笼统 |
| 链接 | 官方或权威获取入口 | 否 | 无法确认写【待确认：需查官方入口】，禁止编造 URL |
| 获取方式 | 公开网站 / 付费标准 / 企业内部 / 数据库订阅 | 是 | 影响他人能否复核 |
| 审核状态 | draft / review / verified / deprecated | 是 | 首期全部为 draft 或 review |

## 2. 引用规范

1. **编号引用**：正文引用来源时写编号加简称，如「依据 R-001（GB/T 24067-2024）」。
2. **禁止引用未登记来源**：出现新来源时必须先登记再引用，登记后方可在公式与因子中引用其编号。
3. **不编造细节**：不得凭印象写出条款号、章节名、页码或表格编号；不确定处写【待确认：需查标准正文对应章节】。
4. **区分版本**：同一标准的多个版本分别登记为不同条目，并注明替代关系。
5. **可复核性**：来源必须让第三方能够找到原文；只有二手转述、没有原始出处的来源不得登记为 L1/L2。

## 3. 如何引用到公式与因子

| 引用场景 | 做法 |
| --- | --- |
| 公式的方法学依据 | 在 `../formulas/formula-register.md` 的「来源/依据」列写来源编号与名称 |
| 因子的数值来源 | 在 `../emission-factors/factor-register.md` 的「来源」列写来源编号与名称；未确认时写「占位」 |
| 术语定义来源 | 在 `../domain/glossary.md` 的「来源」列写来源编号或标准号 |
| 单位换算依据 | 在 `../domain/units-and-conversions.md` 的「换算来源/登记要求」列写来源编号 |
| 边界与口径依据 | 在 `../domain/pcba-smt-processes.md` 与公式文件中注明来源编号 |

## 4. 与其它登记表的关系

- 来源 → 公式：`formula-register.md` 只能引用本子库中存在的编号。
- 来源 → 因子：`factor-register.md` 的因子值必须能回溯到本子库条目。
- 来源变更（改版、废止）时，须同步复核所有引用该来源的公式与因子，并在其变更记录中留痕。
